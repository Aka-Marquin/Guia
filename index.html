Comandos essenciais

git init

Cria uma pasta ".git" no seu dispositivo local, essa pasta armazena todos os commits/atualizações do seu projeto.

git add .

Adiciona todos os arquivos criados no projeto, basicamente deixa todos os arquivos "alinhados" para o commit.

git commit -m "Escreva sua mensagem"

Salva e adiciona uma mensagem descritiva do que foi alterado.

git push -u origin main

Aplica as alterações realizadas no repositorio local (GitHub)

git remote add origin [link do repositorio]

Conecta o repositório local ao repositorio remoto

git fetch

Verifica se o repositório remoto tem modificações em relação ao local.

git pull

Puxa as alterações que foram feitas "externamente", ou seja, o que foi commitado por terceiros (maquinas externas).

git clone [link do repositorio]

Clona um repositório com todo o histórico de commits.

Dica: Utilize o comando "git status" para saber o estado atual do repositorio, no caso, se foi commitado ou não.
